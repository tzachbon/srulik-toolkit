# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability or a report that contains
credentials, private source, or personal data.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/tzachbon/srulik-toolkit/security/advisories/new>

Include the affected skill or file, steps to reproduce the issue, its impact,
and any suggested fix. Remove secrets and unrelated private data from logs or
examples.

The maintainer will acknowledge the report through GitHub and coordinate the
next steps there. Public disclosure should wait until a fix or agreed mitigation
is available.

## Supported versions

Security fixes target the latest version on `main`. Upgrade to the newest
published plugin version before reporting a problem that may already be fixed.
