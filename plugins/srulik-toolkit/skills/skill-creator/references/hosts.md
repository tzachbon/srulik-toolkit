# Select the host mapping

Read only the mapping for the active runtime:

- [Claude Code](claude-code.md): native skill invocation, isolated sessions and
  the optional POSIX description optimizer.
- [Codex](codex.md): namespaced invocation, isolated native plugin installation,
  session resume and telemetry limits.
- [T3 Code](t3-code.md): native questioning, child-task lifecycle and static
  artifact presentation; also read the underlying provider's mapping.

These are capability mappings. A mapping is not proof that a configuration has
been exercised. Record the actual runtime/version and observed evidence; leave
unexercised configurations explicitly unverified.
